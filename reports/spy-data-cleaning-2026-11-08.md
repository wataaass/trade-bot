# moomoo SPY データの洗浄と再計算（2026-11-08、Muse）

Claude からの宿題 (1)「moomoo の SPY を洗った後の月末型の再計算」への対応。

## 方法

- 参照系列: Yahoo Finance の SPY 日次 Adj Close（配当・分割調整済み、1993-01-29〜2026-11-06、8,502本）。Claude の評価基盤と同じ出所に揃えた
- moomoo 系列（US_SPY_daily.csv、autype=1 前方調整、8,472本）と日次リターンを突き合わせ、差が 0.25pt を超える日を「誤バー」として数えた
- 洗浄版は、Yahoo のリターンをそのまま使い、水準だけを moomoo の最終終値に合わせて再構成した（OHLC は同日の係数で比例調整）。ファイル: `data/US_SPY_daily_clean.csv`。元の moomoo 系列は `data/US_SPY_daily_moomoo-original.csv` に保存
- 再計算は self_improve.py の --no-state 実行（状態ファイルは変更しない）。税モデルは同日修正済みの配当源泉 28.2835% 版。**本番の入力ファイルはまだ moomoo 系列のまま**で、切替は Claude との突き合わせ後に判断する

## 誤バーの実態

- 共通営業日 8,469 日のうち、リターン差 0.25pt 超が **146 日**（2000〜2001年に集中、2011年にも点在）
- 最悪の例: 2000-04-05 moomoo +2.65% / 実際 −0.62%、2000-04-04 −3.91% / −0.74%、2011-08-02 0.00% / −2.55%
- 累積成長率（1993〜2026）: moomoo ×20.4 に対して Yahoo ×30.5。moomoo の調整済み系列は年あたり約1.2pt ずつ低く出ていた

## 再計算の結果（窓 2000-05-23〜2026-11-05、税引後）

| 戦略 | moomoo 系列 | 洗浄版（Yahoo） |
|---|---|---|
| 月末型 SMA150 | 税引後 +495.6% / WF Sharpe 0.85 | **+608.0% / 0.88** |
| 月末型 SMA250 | +544.3% / 0.84 | **+588.6% / 0.88** |
| 月末型 SMA200 | +490.5% / 0.82 | +565.4% / 0.87 |
| 二袖月次 SMA200 | +585.0% / 0.72 | +612.2% / 0.72 |
| コア二袖デイリー（現行） | （要参照: zoo 時点 +280.4%） | +277.5% / 0.44 |
| 買い持ち 50/50（対照） | +566.4% / 0.92 | +617.9% / 0.95 |

- 最大下落はほぼ不変（SMA250 −21.2%、SMA150 −29.5%、買い持ち −66.0%）
- **週次評価の筆頭候補が変わった**: moomoo 系列では SMA150 だったが、洗浄版では **SMA250** が筆頭（連続1回目・提案はシャドー条件で保留、今夜の本番実行＝moomoo 系列での公式記録は SMA150 のまま）
- 読み: 絶対水準は洗浄で大きく上がった（moomoo の過小評価が取れた）。一方で税引後の総額では、買い持ちが月末型ファミリーと同等〜わずかに上に出る。月末型の優位は「下落の浅さとリスク調整後」に寄る、という Claude の約100年評価と整合する結果になった
