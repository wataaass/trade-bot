# Claude の考え（判断の理由・迷ったこと・Muse に見てほしい点）

仕様書（`docs/HANDOFF_MUSE.md`）と改良の記録（`reports/improvements.md`）は「何をしたか・結果はどうだったか」。
この文書は「なぜそう判断したか」「どこを疑っているか」をまとめたもの。レビューの手がかりにしてほしい。

## 1. 全体の考え方

- **目標**は、30万円（約 $2,000）を特定口座で運用して、S&P500 の持ち続けより手取りを増やすこと。比べるのは常に「同じ額で SPYM を買って持ち続けた手取り」
- **評価の物差し**は、手数料・約定のずれ・日本の税金（年ごとに通算、損失は3年繰り越し）を引き、最終日に全部売った手取り。元本は本番と同じ $2,000（元本を大きくすると手数料の上限 $22 が効いて甘く出たので、途中で全部やり直した）
- **選び方**は、約300の候補を3つの土俵（約100年の米国株全体、ETF 2003年〜、S&P500 個別株 1997年〜）で走らせ、「税引き後で持ち続けに勝つ」「4つの時代のうち3つ以上で勝つ」「最大下落が持ち続けより10ポイント以上深くない」を満たすものだけを残した
- 残ったのは結局、**「200日線より上ならレバレッジ、下なら短期国債」という古くから知られた型**だけ。凝った型（個別株のスイング、ブレイクアウト、平均回帰など）は、税金と手数料を引くとほぼ全部負けた

## 2. なぜこの型が効くと考えているか

- 米国株の大きな下げ相場は、何か月もかけて進むことが多い（2000〜02年、2008年、1929〜32年）。200日線を割ったところで逃げれば、下げの大部分を避けられる
- 3倍のレバレッジ ETF は、上げ相場では値動きの3倍以上に増えることがあるが、荒れた相場では目減りが大きい。200日線で荒れた相場の多くを避けるので、3倍の弱点が出にくい
- 逆に言うと、**上げ下げを細かく繰り返す相場（ダマシが多い相場）では負ける**。日本や欧州の株価指数で効かなかったのは、このため（改良の記録 9.・10.・54.）
- 金利が高いと、レバレッジ ETF の中の借入コストが重くなり、優位が縮む（27.）。2003年以降の成績は低金利の年が中心なので、今の金利（4% 前後）では控えめに見るべき

## 3. 過剰適合（結果に合わせすぎ）への注意

同じ米国のデータで60項目ほど試したので、たまたま良く見えるものが混ざる余地はある。そのため次の線を引いた。

- **採用するのは「仕組みで説明できる改善」か「新しいパラメータを選んでいないもの」だけ**
  - 49.（B を UPRO と BIL の比率で持つ）: 売る量が減って税金と費用が減る、という仕組みによる改善。新しいパラメータなし
  - 50.（比率を連続的に決める、k = 15%）: 15% は旧版の境目をそのまま使い、選び直していない。k を 8〜30% まで動かしても成績はなめらかに変わり、8つの時代すべてで旧版を上回った
  - 32.（引け間際に発注）: 判定が変わった翌朝は不利な向きに窓を開けやすい、という説明がつき、実物の UPRO で確かめた
- **結果を見て選んだ値は「候補」止まり**
  - B′（k = 20%）は数字が一番良いが、結果を見てから選んだ。ペーパーで A・B と並べて確かめたい
- **最近のデータでだけ良かった変更は入れていない**
  - 戻りの幅 2%（60.）、週1回の見直し（53.）、C の連続版（55.）は、2003年以降では少し良かったが、約100年では差がないので変えていない
- **正直に言うと**、50.の新しい B は「純粋な改善」だけではなく、平均の比率が上がって「少し攻め寄り」になった面もある（2003〜2014年・2018年以降では最大下落が 4〜9 ポイント深い）。点検の目安を -40%／-60% にそろえたのはそのため

## 4. 迷ったこと・判断の理由

- **A と B のどちらを主にするか**: 手取りは A が少し上、下落の浅さは B が上。どちらかに決めず、両方を採用して資金の分け方で調整する形にした。B′ は約100年では A を手取りでも下落でも上回るが、上の理由で候補のまま（57.）
- **損切りやトレーリングストップを入れない理由**: 何通りも試したが、どれも成績が落ちた（8.・22.）。200日線の型は、途中の下げに耐えて大きな上げを取る型で、損切りを足すと別物になる
- **個別株（D）を実験枠にした理由**: バックテストでは良いが、上場廃止の銘柄のデータが欠けていて甘く出ている。$2,000 では10銘柄を整数株で買えず、本番で再現できない
- **年単位で負けても続ける理由**: A・B は半分近くの年で持ち続けに負け、4年続けて負けたこともある（37.）。勝つ年に大きく勝つ型なので、負けた年にやめると勝つ年を取り逃がす。評価は数年単位
- **自動停止を入れない理由**: -40% の下落は過去に何度も普通に起きた深さ。Muse の月末型で使っている -35% 停止をそのまま当てると、通常の値動きで止まってしまう

## 5. Muse に特に見てほしい点

1. **税金の扱い**: 特定口座の年ごとの通算、損失の3年繰り越し、源泉徴収（売るたびに引かれる）、配当の約28%、益出し（61.）。日本の税制の解釈に誤りがないか
2. **参照実装（`tradebot/handoff.py`）と仕様書の食い違い**: 特に `daily_plan` の state の引き継ぎ、不感帯 0.1、`basis` による税金の見込み
3. **合成のレバレッジ ETF の作り方**（借入コスト＝短期金利＋0.5%、信託報酬 0.9%）。実物の UPRO・SSO とは年率で 0.4 ポイント以内で一致したが（33.）、約100年前の金利環境で同じ式でよいか
4. **評価の物差しの穴**: 為替の手数料、外国税額控除、レバレッジ ETF の分配金はほぼ入れていないか、控えめな側で入れている（仕様書4章）
5. **本番口座で確かめてほしいこと**: UPRO・TQQQ が買えるか、売った代金をすぐ次の買いに使えるか
