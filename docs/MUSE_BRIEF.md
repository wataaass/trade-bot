# Muse への依頼文（ユーザーがそのまま渡す用）

もちへ。Claude が bot を約300個作ってバックテストで評価し、ペーパーで動かす候補を厳選した。
仕様書は GitHub の wataaass/trade-bot、ブランチ `claude/effort-estimation-z1y12z` の `docs/HANDOFF_MUSE.md`。
売買判断の参照実装は `tradebot/handoff.py`（検証と同じ判断になることを `tests/test_handoff.py` で確認済み）。

お願いしたいこと:

1. 仕様書の「採用」2つ（A. UPRO⇄BIL、B. UPRO/SSO/SPYM⇄BIL の改良版）を、米国ペーパー口座 1459674 の新しい枠として動かす。各枠の元手は本番と同じ $2,000 にする（手数料の効き方が本番と同じになるように）
2. moomoo 証券（日本）の本番口座で、米国 ETF の売買手数料がいくらかを確かめてほしい（A・B は 0.2% までなら持ち続けに勝つが、低いほど有利）
3. 余力があれば「実験枠」2つ（C. TQQQ⇄BIL、D. 個別株モメンタム6-1 上位10）と、B の境目を 20/35% にした B′（`handoff.target_voltarget(spy, lo=0.20, hi=0.35)`。A とほぼ同じ手取りで下落が浅かった候補）も別枠で動かす
4. 枠ごとに、比較対象の持ち続け（A・B は SPYM か VOO、C は QQQM）と並べて「開始時点＝0%」の累積で報告する
5. 仕様書の数字や判断におかしな点があれば指摘してほしい（レビュー係として）

運用上の注意（仕様書の3章）:

- 判定は引けの終値、発注は**翌営業日の引け間際（NY 15:45〜15:55、日本時間 冬5:45〜／夏4:45〜）に成行**。寄り付き約定は実物の UPRO で年 1〜2 ポイント不利だった（仕様書3章、改良の記録32.）
- A・B の200日線の判定には「非対称の遊び」がある: 200日線を割ったらすぐ逃げ、200日線の +1% を超えたら戻る（間にいる日は前の状態のまま）。`handoff.trend_on` 参照
- 損切りはしない。売るのは判定が変わったときだけ
- A・C は -40%、B は -35% で報告、それより深くなったら運用を見直す。自動停止にはしない（検証では普通に起きる深さのため）
- A・B・C は同じ200日線で動くので、同じ日に一斉に切り替わる（分散にはならない）
- この型は米国株でしか効かなかった（日経平均・米国以外の10か国では持ち続けに負けることが多い）。日本の口座（1570 日経レバなど）には移さない

Claude 側の5枠は 11/7 に停止済み。口座に残っている Claude 枠の建玉の扱いは、ユーザーが決める。

## 更新点（2026-11-08 夜）

- A・B の200日線の判定に「非対称の遊び」を入れた（割ったらすぐ逃げ、+1% を超えたら戻る）。売買が3〜4割減り、2003年〜の手取りが上がった
- すべての数字を本番と同じ元本 $2,000 で計算し直した（元本が大きいと手数料の上限 $22 が効いて甘く出る）
- この型は米国株でしか効かない（日経平均・米国以外の10か国では持ち続けに負けることが多い）。金利が高いほど優位は縮む
- もちの月末型（SPY⇄IEF、SMA250）とも同じ物差しで比べた: 守りの型（7.7%、最大下落 -25%）で、A・B（攻めの型）とは目的が違う。B 50%＋月末型 50% は 10.2%・最大下落 -36% で、持ち続け（9.7%・-55%）より良い組み合わせになる（仕様書1章）
- **発注のタイミングを変更**: 寄り付きではなく、翌営業日の引け間際に成行。寄り付きは実物の UPRO で年1〜2ポイント不利だった
- 判定は毎日行う（週1回に減らすと年1〜2ポイント不利だった）
- moomoo の K線（`autype=1`）の SPY の終値は Yahoo と完全に一致した。1回の取得（370本）で判定に足りる。K線の返り値は `handoff.closes_from_moomoo` でそのまま判断関数に渡せる
- 確定申告をするなら外国税額控除も受ける（持ち続けが年0.2〜0.4ポイント良くなり、A・B との差はその分縮む）
- 退避先は BIL でも SGOV でもよい（SGOV が年0.1〜0.2ポイント良い）
- 試してやめたことも含めた記録は `reports/improvements.md`（1〜45、冒頭に目次）
