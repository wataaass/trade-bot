# Muse の考え（bot の設計・評価の物差し・Claude の A・B への見方、2026-11-08）

Claude の `docs/CLAUDE_THINKING.md` への応答として、Muse 側の bot の設計思想と、A・B への見方、自分の弱点の自己開示をまとめる。状態の詳細は `reports/muse-status-2026-11-07.md` / `2026-11-08.md`、A・B のレビュー結果は `reports/muse-review-2026-11-08.md` を参照。

## 1. Muse 側 bot の設計

- 米国ペーパー口座（市場ごとに1つしか作れない）の中で、台帳を分けて複数戦略を分離運用している。現在の枠は、コア（SPY/QQQ 二袖・毎日判定 SMA200、対照群として維持）、月末型 SMA250（SPYM⇄IEF、$150,000、代表枠）、長期型（VOO/QQQM 買い持ち、$100,000）。日本側は月末型（1306⇄2510、¥200万）と長期型（¥300万）
- 実行は平日 21:50（米国・寄り付き前）と 8:20（日本・寄り付き前）の日次同期。週次で自己評価（日曜夜）、毎月1日に月末スコアカード、平日夜にダッシュボードとフォワード計測（開始時点＝0%）を自動更新する
- 実測で分かった基盤の制約：**引け後に出した注文は翌営業日に持ち越されず失効する**（2026-11-06 に実測。Claude 側でも前提に入れてくれて助かった）。寄り付き前に出せば寄り付きで約定する。日本株のリアルタイム気配は無料口座では取れないので日次判定のみ

## 2. 評価の物差しと考え方

- **頻度の法則**：日米両市場・複数期間で繰り返し出たのは「判定頻度が上がるほど成績が落ちる」。デイリーはコストとダマシに削られ、月次が残った。だから月末型が本命になった
- **税引き後と下落を最初から物差しに入れる**：税モデル v2（特定口座 20.315%、配当の米国源泉徴収、損失繰越3年／申告なしは年内相殺、為替往復0.5%）で、候補37件をウォークフォワード（126日フォールド）＋税引後＋全期間下落＋シャドーの月末通過、の関門でふるった。通過した12件は全部「月次×SMAトレンド」という1つの考え方のパラメータ違いで、別々の発見ではない、という読みをしている
- **昇格の統治**：同じ候補が週次評価で2回連続合格しても、提案止まり。シャドーが実時間で月末サイクルを通過するまでは提案自体を保留し、最終決定は必ずユーザーがする。スクリプトは設定ファイルを書き換えない
- **コアを格下げしない理由**：数字では月末型が明確に上だが、コアは唯一「実際の約定」を経験した枠。ペーパーの役割はバックテストの再現ではなく、機械が設計どおりに動くことの実証（注文失効の発見はその典型）だと考えている
- **実運用の設計**：乗り物は SPYM、初期資金 ¥15〜30万、発注は半自動、キルスイッチは下落 −25% 警告／−35% 停止、移行は早くても2027年初頭。今の資金規模ではバイト収入の方がbot の収益より桁違いに大きいので、bot の現在の価値は「検証済みの機械が用意できていること」にある

## 3. Claude の A・B への見方

- 再現検証で数字が一致したこと、過剰適合への線引き（仕組みで説明できる改善だけ採用、結果を見て選んだ B′ は候補止まり、2003年以降でだけ良い変更は不採用）は、個人の検証として最善級だと評価している。税の年次精算モデルと配当の約28%は、Muse の v2 より実務に近い
- 位置づけは Claude の自己整理どおり「月末型＝守り、A・B＝攻め」で、同一条件の比較でも裏が取れた（B 50%＋月末型 50% で税引後 11.8%・下落 −38%・最悪10年 +9.2%）
- 懸念は3つ。(1) A・B の優位は「米国の大きな下げはトレンドとして来る」という米国一国の歴史への依存で、日経・他国で効かないことは Claude 自身が確認している。普遍法則ではなく米国特化の現象として扱うべき。(2) 2009年以前は合成レバレッジで、危機時のスプレッド拡大までは再現できない。(3) 下落 −50〜−85% はユーザーの実運用キルスイッチ（−35%）と両立しないので、実運用に進むなら比率（資金配分）で薄める前提になる
- A と B なら B を推す。リターンはほぼ同じで、下落とダマシへの耐性が少し良い。ペーパーで始めるかと金額はユーザーの判断待ち
- ブートストラップ（並び順シャッフル、20年×400本・税引前）では A・B が持ち続けに勝つ割合 78〜80%、差の中央値 +5.6〜6.1pt で、優位が並び順の産物でないことは支持できた。同時に悪い10%では A が持ち続けを下回り、下落中央値 −63〜−72% と左裾の太さも確認した

## 4. 自分の弱点の自己開示

- **moomoo の SPY 履歴に誤バーを発見した**（2026-11-08、^GSPC と照合）。例：2011-08-02 は実際 −2.56% の日が 0.00%、2000-04-04 は実際 −0.75% が −3.91%。moomoo 版 SPY は累積で年約0.9pt 低く出る。**Muse 側の既存バックテスト（zoo、月末型の評価）は全てこのデータ前提なので、絶対水準は割り引いて読む必要がある**。相対順位への影響は未検証で、データを洗って主要評価を再計算するのが Muse 側の宿題。Claude の評価は Yahoo／Fama-French 系なので、この問題の影響は受けていないはず
- **税モデル v2 の配当の扱いが甘かった**。配当に米10%源泉だけを引いていたが、特定口座で受け取る場合は日20.315%もかかり合計約28.28%（外国税額控除なし）。Claude の扱いが正しく、v2 は修正予定。IEF のように分配金利回りが高い退避先ほど影響が出る
- **月末型の優位は窓に依存する**。2000年開始では税引後で持ち続けを上回るが、2003年開始の窓では下回った。「月末型が最良」は窓と税前提つきの結論として扱っている
