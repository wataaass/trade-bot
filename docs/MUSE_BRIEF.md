# Muse への依頼文（ユーザーがそのまま渡す用）

もちへ。Claude が bot を約300個作ってバックテストで評価し、ペーパーで動かす候補を厳選した。
仕様書は GitHub の wataaass/trade-bot、ブランチ `claude/effort-estimation-z1y12z` の `docs/HANDOFF_MUSE.md`。
売買判断の参照実装は `tradebot/handoff.py`（検証と同じ判断になることを `tests/test_handoff.py` で確認済み）。

## お願いしたいこと

1. 仕様書の「採用」2つを、米国ペーパー口座 1459674 の新しい枠として動かす。各枠の元手は本番と同じ $2,000（手数料の効き方が本番と同じになるように）
   - **A**: SPY が200日線より上なら UPRO 100%、下なら BIL 100%
   - **B**: A と同じ判定で逃げる。持つときは UPRO の比率 = min(1, 15% ÷ 前月末の20日の値動き)、残りは BIL
   - どちらも `handoff.daily_plan(bot, spy_close, holdings, cash, prices, state)` 1つで、判定・注文・翌日に引き継ぐ状態が得られる。移植はこの関数を基準にすると間違いが少ない
2. 余力があれば別枠で: **B′**（B の 15% を 20% にした版。A と同じかそれ以上の手取りで下落が浅かった候補）、実験枠の **C**（QQQ が200日線より上なら TQQQ、下なら BIL）と **D**（個別株モメンタム6-1 上位10）
3. 枠ごとに、比較対象の持ち続け（A・B・B′ は SPYM か VOO、C は QQQM）と並べて「開始時点＝0%」の累積で報告する
4. moomoo 証券（日本）の本番口座で、売った代金をその場で次の買いに使えるか（受け渡し前の買付余力に入るか）を確かめてほしい
5. 仕様書の数字や判断におかしな点があれば指摘してほしい（レビュー係として）

## 運用のきまり（仕様書の3章）

- **判定**は毎日、確定した終値で。**発注**は翌営業日の引け間際（NY 15:45〜15:55、日本時間 冬 5:45〜／夏 4:45〜）に成行。寄り付きの約定は実物の UPRO で年 1〜2 ポイント不利だった
- 200日線の判定には「非対称の遊び」がある: 割ったらすぐ逃げ、+1% を超えたら戻る（間にいる日は前の状態のまま）。`handoff.trend_on`
- B の比率は月1回（月初）だけ見直し、前回の目標から 0.1 未満の変化は無視する。**目標が変わった日だけ、差の分を売買する**（全部は売り替えない。値動きで比率がずれても直さない）
- 損切りはしない。売るのは判定が変わったときだけ
- 下落率 -40% で報告、-60% で運用を見直す（A・B・B′・C 共通）。自動停止にはしない（検証では普通に起きる深さのため）
- A・B・C は同じ200日線で動くので、同じ日に一斉に切り替わる（分散にはならない）
- この型は米国株でしか効かなかった（日経平均・米国以外の10か国では持ち続けに負けることが多い）。日本の口座（1570 日経レバなど）には移さない

## daily_plan の使い方の注意

- `state` は枠ごとに保存し、翌日そのまま渡す（初日は None）。注文が約定しなかった日は state を更新せず、翌日もう一度呼ぶ
- 積み立てで入金した日は `deposit=入金額` を渡す（その額だけを今の目標の比率で買い足す）
- 退避先を SGOV にするなら `safe="SGOV"`
- 本番の源泉徴収ありの口座では、利益の出る売りから約20%が引かれるので、`basis={銘柄: 1株あたりの取得単価}` を渡す（買いの量を税金の分だけ減らし、買付余力不足で買いが通らないのを防ぐ）
- 価格は moomoo の履歴K線（`autype=1`）でよい。SPY の終値は Yahoo の調整済み終値と完全に一致し、1回の取得（370本）で判定に足りる。`handoff.closes_from_moomoo` でそのまま渡せる
- 移植した bot は、過去の値段で毎日動かして手取りを比べると誤りに気づける。参照実装で同じことをした結果は `scripts/replay_handoff.py`（2010〜2026年の実物で A 17.4%、B 16.2%、B′ 17.5%）

## 確認済みのこと

- moomoo の米国株の取引手数料は 0.132%（上限 $22）で、検証の前提と同じ（公式ページ）
- moomoo のアプリには引け成行（MOC）注文がある。UPRO・BIL は NYSE Arca 上場で、締切はニューヨーク時間 15:50（15:45 以降は取消不可）。API からは成行しか確認できていないので、bot は引けの5〜15分前に成行で出す
- 新しい B は、発注の遅れ・約定のずれ 0.3%・借入コスト +1% のどの悪条件でも持ち続けを上回った。毎月積み立てても優位は変わらない
- もちの月末型（SPY⇄IEF、SMA250）は守りの型（7.7%、最大下落 -25%）で、A・B（攻めの型）とは目的が違う。B 50%＋月末型 50% は 11.6%・最大下落 -44%（仕様書1章）
- 確定申告をするなら外国税額控除も受ける。損失が出た年は確定申告で3年繰り越す
