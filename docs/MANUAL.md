# A・B を手で回すときの手順（本番用）

bot が止まったとき、または半自動（bot が判定 → 自分が承認 → 発注）で運用するときの手順。
ルールの詳しい説明は `docs/HANDOFF_MUSE.md` の3章。

## 毎日やること（平日の夜〜翌朝）

1. **判定を確かめる**（ニューヨークの引けの後、日本時間で朝6時以降）
   - `python scripts/signal_today.py` を実行するか、Muse の報告を見る
   - 見るのは「A → UPRO か BIL か」「B → UPRO の比率（残りは BIL）」
2. **今持っているものと同じなら、何もしない**（ほとんどの日はこれで終わり。年に4〜6回しか切り替わらない）
   - 確認は毎日する。週1回に減らすと、逃げるのが遅れて年1〜2ポイント不利だった
3. **違っていたら、翌営業日の引け間際に乗り換える**
   - 時刻: ニューヨーク時間 15:45〜15:55（日本時間 冬は 5:45〜5:55、夏は 4:45〜4:55）
   - 13:00 で終わる短縮取引日（感謝祭の翌日、クリスマスイブなど。2026年は11月27日・12月24日）は、ニューヨーク時間 12:45〜12:55（日本時間 翌日 2:45〜2:55）
   - 今の銘柄を全部「成行・売り」、そのお金で新しい銘柄を「成行・買い」（整数株で買えるだけ、現金を1%残す）
   - 寄り付き（日本時間の夜11時半や10時半）には出さない。実物で年1〜2ポイント不利だった
   - B は、目標の比率が変わった分だけ売買する（例: UPRO 100% → 75% なら UPRO を4分の1売って BIL を買う）。全部は売り替えない。`handoff.plan_rebalance` が株数を出す

## お金を追加するとき（積み立てなど）

- 入金したドルで、**その時点の判定の銘柄**を買い足す（A なら UPRO か BIL、B なら今の目標の比率で UPRO と BIL）。売買のタイミングは乗り換えと同じく、引け間際
- 今持っている分を売って配分し直すことはしない（売ると税金がかかる）
- 円からドルへの両替は、入金のときに1回だけ
- 毎月積み立てても、持ち続けに対する優位は変わらない（20年の窓で確認、`reports/improvements.md` の48.）

## 判定の中身（自分で確かめたいとき）

- **200日線**: SPY の直近200営業日の終値（配当込みの調整後）の平均
- SPY の終値が200日線を**下回ったら** → 逃げる（BIL）
- SPY の終値が200日線の**1%上を上回ったら** → 持つ
- その間（200日線〜+1%）なら、前の日の状態のまま
- B の比率: 毎月の最終営業日に、直近20営業日の値動き（日次リターンの標準偏差 × √252）を見て、UPRO の比率 = 15% ÷ 値動き（100% が上限）、残りは BIL。翌月はずっとその比率。前の比率との差が 0.1（10%）未満なら変えない。値動きで比率がずれても直さない
- B′（候補）を使う場合は、15% を 20% にするだけで、ほかは B と同じ

## してはいけないこと

- **途中で損切りしない**。下がっても、200日線を割るまでは持つ。損切りを足すと、検証した型とは別物になって成績が落ちた
- **急落の翌日に慌てて売らない**。1日で大きく下げた翌日に逃げる案も、成績が落ちた
- **円に戻さない**。乗り換えのたびに円に戻すと、為替の手数料が往復でかかる。ドルのまま次を買う
- **日本株（日経レバなど）に同じことをしない**。米国以外では効かなかった

## 下がったとき

- A・B とも -40% まで下がることは、過去に何度もあった。ルール通りなら持ち続ける
- A・B とも -60% を超えたら、運用そのものを見直す（自動では止めない）
- 1987年のような1日 -20% の急落では、A・B とも約 -73% まで落ち、元に戻るまで約8年かかった。これに耐えられない額は入れない

## 負けている年が続いても

- A・B は、年単位では半分近くの年で持ち続けに負ける。4年続けて負けたこともある
- 勝つ年に大きく勝って、長い目で上回る型。負けた年にやめると、勝つ年を取り逃がす
- 評価は数年単位で行う

## 税金（年に1回）

- 源泉徴収ありの特定口座なら、売るたびに税金が引かれるので、ふだんは何もしなくてよい
- **損失が出た年は確定申告をする**。損失を3年繰り越せて、年 0.3〜0.7 ポイント手取りが増える
- 確定申告をするなら、外国税額控除（米国で引かれた配当の10%）も受ける
- 年末の損出しはしなくてよい（効果がなかった）

## 記録

- 乗り換えた日、銘柄、株数、約定価格を残す（Muse の台帳、または自分のメモ）
- 比べる相手は「同じ日に同じ額で SPYM を買って持ち続けた場合」
