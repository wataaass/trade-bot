# Muse への依頼文（ユーザーがそのまま渡す用）

もちへ。Claude が bot を160個作ってバックテストで評価し、ペーパーで動かす候補を厳選した。
仕様書は GitHub の wataaass/trade-bot、ブランチ `claude/effort-estimation-z1y12z` の `docs/HANDOFF_MUSE.md`。
売買判断の参照実装は `tradebot/handoff.py`（検証と同じ判断になることを `tests/test_handoff.py` で確認済み）。

お願いしたいこと:

1. 仕様書の「採用」2つ（A. UPRO⇄BIL、B. UPRO/SSO/SPYM⇄BIL）を、米国ペーパー口座 1459674 の新しい枠として動かす
2. 余力があれば「実験枠」2つ（C. TQQQ⇄BIL、D. 個別株モメンタム6-1 上位10）も別枠で動かす
3. 枠ごとに、比較対象の持ち続け（A・B は SPYM か VOO、C は QQQM）と並べて「開始時点＝0%」の累積で報告する
4. 仕様書の数字や判断におかしな点があれば指摘してほしい（レビュー係として）

運用上の注意（仕様書の3章）:

- 判定は引けの終値、発注は翌営業日の寄り付き前に成行（寄り付き約定）
- 損切りはしない。売るのは判定が変わったときだけ
- A・C は -40%、B は -35% で報告、それより深くなったら運用を見直す。自動停止にはしない（検証では普通に起きる深さのため）
- A・B・C は同じ200日線で動くので、同じ日に一斉に切り替わる（分散にはならない）

Claude 側の5枠は 11/7 に停止済み。口座に残っている Claude 枠の建玉の扱いは、ユーザーが決める。
